Database recovery

Encrypted backups.
A path to recovery.

School Exam Backups is a private utility operated by the school examination application's owner to create encrypted PostgreSQL database snapshots for recovery. It uploads uniquely named encrypted archives to a private Google Drive folder and checks ownership, sharing permissions and transfer consistency.

Setup in progress

The unattended GitHub Actions backup job is planned and has not been enabled. No live database backup has been completed through this setup yet.

01

Encrypt before upload

Database exports stream into age encryption before the archive reaches Google Drive.

02

Use a private destination

The utility checks the destination folder's ownership and sharing permissions before an upload.

03

Keep recovery separate

The private recovery key is kept separately from the runner and cloud storage. A protected copy is essential.
